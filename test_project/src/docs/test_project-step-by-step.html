Recovery

  • exit 2 + "error: ..." = usage/data problem (bad column, bad fit file, empty cut). Fix input, rerun.
  • Huge reduced chisq on real data with err=1.0 usually means missing error column — supply --err-col.
  • Pure-decay models cannot fit a rising edge (seen on B4 full range); fit the tail or add a rise term.
  • Freeing both amplitude and time-offset of one exponential is degenerate — keep offsets fixed.
