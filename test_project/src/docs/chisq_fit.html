chisq_fit (v0.0.2, 2026-09-23)

Purpose

Chi-square fit of CSV columns to a user function. Exit 0 ok, 2 usage/data error.

Usage

python3 src/scripts/chisq_fit.py csvfile [--x-col C] [--y-col C] [--err-col C]
  [--x-limits lo,hi] [--plot-x-limits lo,hi] [--plot-y-limits lo,hi]
  [--axis-type x-y] [--with-bin {uniform,std,mad}] [--with-bin-per P] [--n-bins N]
  [--plot F] [--plot-only] [--fit F.py]

Options

Fit-file format

fitfunction = "double_exp"      # selects a function defined below
fit_range = "7000,800000"       # string "lo,hi" or (lo, hi) tuple
fit_parameter_filename = "/path/params.txt"
A1 = "5000:T:(0,20000)"         # "init : T|F|- : (lo,hi)|-"; tuples also accepted
t01 = "0:F:-"                   # F = hold at init; T = fit
def double_exp(x, A1, tau1, t01, A2, tau2, t02, C0):
    return A1*exp(-(x-t01)/tau1) + A2*exp(-(x-t02)/tau2) + C0

Tested examples

python3 src/scripts/chisq_fit.py devl/testdir/data/B4_fixed.csv --plot-only --plot /tmp/p.png
python3 src/scripts/chisq_fit.py devl/tmp/synth_twoheader.csv --fit devl/tmp/synth_fit.py --plot /tmp/f.png
# -> A=25.13 mu=5.00 sig=1.83, chisq=3.74 dof=8 reduced=0.47
python3 src/scripts/chisq_fit.py devl/testdir/data/B4_fixed.csv --x-limits "20000,800000" --with-bin uniform --n-bins 60 --fit <double_exp> --axis-type lin-log --plot /tmp/t.png

Troubleshooting

  • Bad column/fit file/empty cut → exit 2 with message.
  • Non-positive data on log axes → matplotlib/scipy error, exit 2.
  • Amplitude+offset free together → degenerate uncertainties.
