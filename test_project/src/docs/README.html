test_project — chi-square fitting CLI (v0.0.2)

Purpose

Fit columns of a CSV file to arbitrary user-supplied functions by chi-square minimisation, with optional binning (uniform/std/mad), y-error handling, x-limits vs plot-limits, axis scaling, plot-only preview, and plot + parameter file outputs.

Requirements

Python 3 with numpy, scipy, matplotlib, astropy. Tested with numpy 2.3.5, scipy 1.16.3, matplotlib 3.10.6, astropy 7.1.1.

Install / run

No installer at v0.0.2. Run from the project root:

python3 src/scripts/chisq_fit.py --help

Quickstart (tested)

python3 src/scripts/chisq_fit.py devl/testdir/data/B4_fixed.csv --plot-only --plot /tmp/preview.png
python3 src/scripts/chisq_fit.py devl/tmp/synth_twoheader.csv --fit devl/tmp/synth_fit.py --plot /tmp/fit.png

Inputs

  • CSV: row 1 = column names; optional row 2 = units; rest numeric data. 1-header and 2-header files both accepted (units row auto-detected).
  • Fit file (format): fitfunction, fit_range, parameter specs NAME:<init>:<T|F|->:<(lo,hi)|->, fit_parameter_filename, plus the function definitions.

Outputs

  • Console best-fit parameters, chi-square, dof, reduced chi-square.
  • Plot file (--plot). Parameter file (path from fit file).
