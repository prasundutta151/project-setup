Create a command-line program with argparse (parser built in a separate
function) that: (1) reads multi-column CSV (line 1 = column names, line 2 =
units); (2) selects x/y/err columns with defaults to first three, std(y)
fallback, else 1.0; (3) supports data x-limits and separate plot x-limits via
same "lo,hi" syntax; (4) supports --plot-only; (5) supports axis-type
combinations of log/lin/exp; (6) supports --with-bin {uniform,std,mad} +
--with-bin-per (default 10); (7) supports --plot <filename>; (8) supports
--fit <custom.py> with fitfunction choice, fit range, parameter specs
A:<init>:T:(low,high) (T=fit, F=fixed, -=skip), fit_parameter_filename, and
multiple function definitions; (9) performs chi-square fitting with/without
binning and with/without y-errors.

# TASK

## Objective
Build a CLI Python tool (using `astropy` where relevant) that performs chi-square fitting of tabular CSV data to arbitrary user-supplied functions, with optional data binning, y-error handling, x/range limits, axis scaling, plot-only preview, and plot/file outputs.

## Requirements
- R1: CLI with `argparse`, parser construction isolated in a separate function.
- R2: CSV reader handling two header rows (names + units), arbitrary multi-column data.
- R3: Column selection: `--x-col`, `--y-col`, `--err-col` (names or 0-based indices); default first three columns; fallback errors: std(y) if x,y given but no err; 1.0 if no error info.
- R4: X data limits and separate plot X limits, each accepting lower,upper in one CLI option.
- R5: `--plot-only` flag: show/save data plot, skip fitting.
- R6: Axis-type option (e.g. `--axis-type log-exp`): all combinations of log/lin/exp.
- R7: Binning: `--with-bin {uniform,std,mad}` + `--with-bin-per` (% tolerance, default 10).
- R8: `--plot <filename>`: save fit/data plot.
- R9: `--fit <file.py>`: fitfunction choice, fit range, parameter specs, fit_parameter_filename, multiple function defs.
- R10: Chi-square fitter (astropy-assisted) with/without binning and with/without y-errors.
- R11: Parameter output file written to `fit_parameter_filename`.
- R12: Sensible exit codes / error messages for missing file, bad columns, bad fit file, empty selection.

## Inputs
- Multi-column CSV: row1 = names, row2 = units, rest = data.
- CLI args: csv path, x/y/err selectors, x-limits, plot limits, axis-type, binning, plot filename, fit file, plot-only.
- Custom fit `.py`: `fitfunction`, fit-range, params (`NAME:<init>:<T|F|->:<(low,high)|->`), `fit_parameter_filename`, function defs.
